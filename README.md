# 精霊チェッカー（Sprite Check）

精霊の所持状況を記録し、シーズンごとに一覧を確認できるチェックリストです。

**アプリを開く：** https://mylifereading6666-oss.github.io/Sprite-Check/

> このREADMEは現在の画面に合わせた使い方ガイドです。検索ボックス・「登場予定」フィルター・編集画面のレベル設定はありません。

## 画面の見方

### 1. 精霊カードを確認する

![精霊カードの画像例：Jonesy Sprite](https://fortnite.gg/img/x/sprites/icons/T_Icon_BR_Creature_Sprite_Jonesy_L.webp)

カードには、精霊の画像と名前、シーズン、レアリティ、所持状況などが表示されます。変異が登録されている精霊は、カード内に変異ごとの選択欄が表示されます。

### 2. シーズンで絞り込む

画面上部のシーズン選択を使うと、表示する精霊を切り替えられます。

- **全シーズン**：登録されているすべてのシーズンを表示
- **チャプター7 シーズン4（現行）**：現行シーズンの精霊を表示
- **チャプター7 シーズン3（過去）**：過去シーズンの精霊を表示

### 3. 並び替える

シーズン選択の隣にある並び替えメニューで、一覧の順序を変更できます。

- **名前順**：精霊名の順に表示
- **レベル順**：レベル情報の順に表示
- **所持優先**：所持している精霊を先に表示

※編集画面にはレベル設定欄がありません。レベル順は、既存データに保存されているレベル情報に基づきます。

### 4. 所持・未所持・Masterを切り替える

![精霊の変異画像例：Jonesy Sprite Cheatmaster](https://fortnite.gg/img/x/sprites/icons/T_Icon_BR_Creature_Sprite_Jonesy_Cheatmaster_L.webp)

絞り込みボタンを押すと、表示するカードを切り替えられます。

- **すべて**：すべての登録精霊を表示
- **所持**：所持としてチェックした精霊を表示
- **未所持**：所持にしていない精霊を表示
- **Master**：Masterとしてチェックした精霊を表示

カード内の「所持にする」チェックボックス、または変異ごとのボタンを操作して所持状況を記録します。Masterの設定や変異ごとの状態は、精霊の編集画面から変更できます。

## 精霊を追加・編集する

### 新しい精霊を追加する

1. 「＋ 追加」を押します。
2. 精霊名を入力します（必須）。
3. 必要に応じてレアリティを選択します。
4. 画像を設定します（任意）。
   - **画像URL**：画像のURLを入力します。
   - **端末から画像を選択**：スマートフォンやパソコンに保存した画像を選びます。画像は縮小・圧縮して保存されます。
5. 所持・Masterなどの項目を設定します。
6. 保存します。

### 既存の精霊を編集する

1. 対象のカードにある「編集」を押します。
2. 名前、レアリティ、画像、所持、Masterなどを変更します。
3. 保存します。

変異がある精霊は、編集画面で変異ごとの画像・所持・Masterなども設定できます。不要な項目を変更しないように注意し、保存前に内容を確認してください。

### 画像について

![精霊画像の例：Jonesy Sprite Gold](https://fortnite.gg/img/x/sprites/icons/T_Icon_BR_Creature_Sprite_Jonesy_Gold_L.webp)

- 画像URLには `https://` または `http://` で始まる画像のURLを入力してください。
- 端末から画像を選ぶ場合は、画像ファイルを選択してください。
- 外部サイトの画像は、URLが無効になったり、配信元の仕様が変わったりすると表示されなくなることがあります。
- 外部画像は画像データ自体をアプリに保存しないため、オフライン時に表示されない場合があります。

## データのバックアップと復元

### JSONバックアップを保存する

1. **データ管理**まで移動します。
2. **JSONバックアップ**を押します。
3. ダウンロードされたJSONファイルを、端末内だけでなく安全な別の場所にも保管してください。

### バックアップを復元する

1. **バックアップを復元**を押します。
2. 以前保存したJSONファイルを選びます。
3. 現在のデータを置き換える確認が表示されたら、対象ファイルが正しいことを確認してから続行します。

**注意：復元は現在のデータを置き換えます。** 復元前に、必要であれば現在のデータもバックアップしてください。

### 全データ削除

**全データ削除**は、登録した精霊とチェック状況を削除する操作です。取り消せないため、実行前に必要なバックアップがあることを確認してください。

## 保存場所・オフライン利用・注意点

- 登録データとチェック状況は、使用中のブラウザの端末内ストレージに保存されます。
- データは端末間で自動同期されません。同じURLを別の端末で開いても、チェック状況は共有されません。
- ブラウザのサイトデータを消去した場合や、端末を変更した場合、データが失われる可能性があります。定期的にJSONバックアップを保存してください。
- 初回利用時はインターネット接続が必要です。アプリ本体がキャッシュされた後は、対応ブラウザでオフライン利用できる場合があります。
- オフラインでの動作や外部画像の表示は、ブラウザや通信環境によって異なります。
- 画像は画面例として掲載しています。シーズン分類や精霊の情報は、ゲーム内の最新情報と照合して利用してください。

## ホーム画面に追加する

スマートフォンでは、アプリのURLをブラウザで開き、ブラウザメニューの**ホーム画面に追加**（または同等の項目）を選ぶと、ホーム画面から起動しやすくなります。メニュー名や対応状況はブラウザによって異なります。

## 精霊一覧画像を作成・共有

「データ管理」内の **精霊一覧画像を共有** または **精霊一覧画像をダウンロード** を押すと、登録済み精霊の一覧PNGを作成できます。ベースと各変異について、それぞれ所持／未所持、レベル、Master／未Masterを表示します。精霊ごとの代表画像と項目名を掲載し、変異ごとの画像は掲載しません。共有ボタンは対応端末で共有メニューを開き、ダウンロードボタンはPNGを端末に保存します。作成画像は個人の非営利なファン活動の範囲で共有できます。ゲーム由来の画像・名称など第三者素材の権利は各権利者に帰属します。
