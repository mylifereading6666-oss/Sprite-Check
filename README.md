# 精霊チェッカー（Sprite Check）

スマートフォン向けのオフライン対応チェックリストです。登録データは利用中のブラウザの `localStorage` に保存され、サーバーやアカウントへ送信されません。

## 公開方法
GitHub リポジトリの Settings → Pages で、Build and deployment の Source を `Deploy from a branch`、Branch を `main`、フォルダーを `/(root)` に設定して保存します。公開URLは通常、次のとおりです。

https://mylifereading6666-oss.github.io/Sprite-Check/

GitHub Pages の反映には数分かかることがあります。URLがすぐ開けない場合は、Settings → Pages に表示される公開ステータスを確認してください。

## 使い方
- 「＋ 追加」から精霊を登録し、所持・レベル・Master・登場予定・新着を管理します。
- 検索欄やフィルターで表示を絞り込めます。
- 「JSONバックアップ」でデータを書き出し、「バックアップを復元」で読み込めます。
- 対応ブラウザでは、公開URLを一度開いたあと、ブラウザメニューからホーム画面に追加できます。

## オフラインとデータ保存
- 初回は公開URLへの接続が必要です。Service Worker が対応ブラウザでアプリ本体をキャッシュすると、次回以降はオフラインでも開ける場合があります。
- チェック状況は端末・ブラウザごとです。他の端末への自動同期はありません。
- ブラウザのサイトデータ消去や端末変更などでデータが失われることがあります。JSONバックアップを別の場所に保存してください。
- 画像URLは画像そのものを保存しません。外部画像はオフライン時に表示されないことがあります。
- サンプル名は入力例であり、公式の精霊一覧や最新情報として確認したものではありません。

## ファイル
- `index.html`: アプリ本体
- `manifest.webmanifest`: ホーム画面追加用メタデータ
- `sw.js`: アプリ本体のキャッシュ
- `icon.svg`: アプリアイコン
